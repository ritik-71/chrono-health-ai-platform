# ChronoHealth AI - Complete Technology Stack Report

## 1. Frontend Layer
- **Framework**: Next.js 14 (App Router)
* **Language**: TypeScript (Strict Mode)
* **Styling**: Tailwind CSS
* **Animations**: Framer Motion
* **Visualization**: Recharts (Responsive, Animated)
* **Icons**: Lucide React
* **Theme Management**: next-themes (System, Dark, Light)
* **API Client**: Axios (with custom interceptors for backend sync)
* **Exports**: jsPDF, html2canvas (Dynamic dashboard-to-PDF conversion)

## 2. Backend Layer
- **Framework**: FastAPI (High-performance Python ASGI)
* **Server**: Uvicorn
* **Database Toolkit**: SQLAlchemy 2.0 (AsyncIO support)
* **Data Validation**: Pydantic v2
* **Migrations**: Alembic
* **Environment**: Python 3.11+

## 3. Artificial Intelligence & Machine Learning
- **Core Inference**: XGBoost, LightGBM (Gradient Boosted Trees)
* **Explainability**: SHAP (SHapley Additive exPlanations)
* **Reinforcement Learning**: Custom Q-Learning Implementation
* **Preprocessing**: Scikit-learn (StandardScaler, LabelEncoder)
* **Natural Language**: Custom Pattern-Matching NLP for AI Assistant
* **Computation**: NumPy, Pandas

## 4. Database & Storage
- **Production DB**: Neon PostgreSQL (Serverless)
* **Development DB**: SQLite
* **File Handling**: Multipart Form Data for CSV/JSON ingestion

## 5. Deployment & DevOps
- **Frontend Hosting**: Vercel
* **Backend Hosting**: Render (Web Service)
* **Containerization**: Docker (Multi-stage builds)
* **Version Control**: Git / GitHub
